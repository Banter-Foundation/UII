## Summary

The document tree is the hub: import format A, export format B, and a round trip compares equal. Markup formats parse HTML. Code formats carry one `uii` record per node plus the toolkit's own calls, and import rejects a file that is missing a required call. Raven was looked up in Banter-Foundation/Banter before any Raven symbol was emitted. That repository has no Raven name. The custom imgui format uses the public C API from oscar-soirey/Raven together with Dear ImGui docking, tables, and child windows. Toolkits that have no child window or dock space do not get those calls. No editor window was added.
